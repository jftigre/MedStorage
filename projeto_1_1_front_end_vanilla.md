# Projeto 1.1 — Front-end Vanilla

**Pontuação total:** 100 pontos — **Nota:** de 0 a 100

Esta atividade consiste em desenvolver a primeira etapa do projeto da disciplina, especificamente implementando o front-end de uma aplicação Web conforme a proposta definida. Mostre no código como foram aplicados os seguintes aspectos:

## Critérios de avaliação

| Critério | Descrição | Pontuação |
|---|---|---:|
| Uso de Programação Funcional | Transformação de dados com `map()`, `filter()` e/ou `reduce()`. | 15 pts |
| Uso de ESM (ECMAScript Modules) | Organização do código com `import` e `export` e separação de responsabilidades. | 10 pts |
| Estruturação de Dados | Organização dos dados em arrays em memória ou persistência com LocalStorage (ou json-server). | 20 pts |
| Manipulação do DOM e Componentes Dinâmicos | Criação manual de componentes (`createElement`, `appendChild`, etc.). | 20 pts |
| Tratamento de Eventos | Captura de cliques, submissão de formulários e alterações em campos. | 20 pts |
| Uso do Vite (Template Vanilla) | Configuração e execução do projeto com o template vanilla do Vite. | 15 pts |
| Uso de Bibliotecas | Biblioteca auxiliar e sua finalidade no projeto. | Opcional |

## Aspectos a demonstrar no código

- **Uso de Programação Funcional — 15 pts:** Como foram utilizados métodos de programação funcional, como `Array.map()`, `Array.filter()` e/ou `Array.reduce()`, para manipulação e transformação de dados dentro da aplicação?
- **Uso de ESM (ECMAScript Modules) — 10 pts:** Como o código JavaScript foi organizado utilizando ESM (ECMAScript Modules), demonstrando a separação de responsabilidades entre arquivos e o uso de `import` e `export`?
- **Estruturação de Dados (LocalStorage ou JSON/Array) — 20 pts:** Como os dados utilizados na aplicação foram organizados e manipulados, seja por meio de arrays em memória ou utilizando persistência com LocalStorage (ou json-server)?
- **Manipulação do DOM e Criação de Componentes Dinâmicos — 20 pts:** Como o DOM foi manipulado para construção da interface? Descreva como os componentes foram criados dinamicamente de forma manual (sem uso de frameworks como Angular, React ou Vue), utilizando métodos como `createElement`, `appendChild` ou similares, a partir dos dados da aplicação. (Tente incluir no mínimo um CRUD.)
- **Tratamento de Eventos — 20 pts:** Como os eventos de interação do usuário (como cliques em botões, submissão de formulários ou mudanças em campos) foram tratados no JavaScript?
- **Uso do Vite (Template Vanilla) — 15 pts:** Como foi realizada a configuração e utilização do Vite com o template vanilla para criação e execução do projeto?
- **Uso de Bibliotecas (opcional):** Foi utilizada alguma biblioteca auxiliar (exceto frameworks de componentes como Angular, React ou Vue)? Se sim, explique qual foi utilizada e sua finalidade no projeto.

## Observações finais e diferenciais (Vanilla)

Serão considerados como diferenciais no projeto aspectos como:

- Qualidade da documentação (`README.md` claro e completo);
- Experiência do usuário (UX);
- Responsividade da interface;
- Cuidado com o visual e a estilização;
- Organização e estrutura do código.

Esses elementos contribuem diretamente para a qualidade final da aplicação e refletem boas práticas no desenvolvimento front-end.
